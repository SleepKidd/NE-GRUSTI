# NE-GRUSTI

A small single-page web project by SleepKidd.

## Structure

- `index.html` — the application and page markup.

## Run locally

No build step is required. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/SleepKidd/NE-GRUSTI.git
cd NE-GRUSTI
```

Then open `index.html` with your browser.

## Development

For changes, create a branch and keep commits focused so they are easy to review.
